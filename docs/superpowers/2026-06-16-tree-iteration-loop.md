# 量化决策树迭代循环（大数据 + screen 验证台）

- 起：2026-06-16（/loop 自驱，≥10 迭代：回测→观察→思考→改树→下一轮）
- 数据：全市场 survivorship-free top-2000（`data/universe_membership.csv` 5194 + `membership_top2000.csv`），2018–2026 含 2018/2022 熊 + 2019-21 牛 + 2023-25。
- 验证台：`rquant screen --backtest`（横截面 top-N、regime 切片、优质分层、OOS 经 --from/--to）。基准 = top-2000 等权无成本；成本单边 10bps。
- 既有诚实结论（出发点）：**PB 价值是唯一有横截面预测力的基本面信号，但仅防御**（cheapest-N long-only 全程跑输宽基准、熊市超额正）；**价值+动量证伪**（动量在便宜池内前瞻为负）；质量/成长证伪；纯技术在大盘弱。
- **§5.3 纪律**：genuinely 探索、敏感面看稳健性、**不调参凑尖峰**；falsification 是有效产出。每轮记 OOS（2023-2026）超额 + Sharpe + maxDD + 2018/2022 熊切片 + 诚实判定。

**迭代 1-4 阶段结论**：
- **便宜池内任何二级技术 tilt（动量/低波/反转）都恶化**——浓缩+换手+噪声毁分散。纯价值篮最优。
- **更宽的价值篮（top 100-200）改善风险调整**（Sharpe 0.31→0.39、maxDD~0.18）——价值溢价靠分散表达；但**全程+OOS 超额仍负**（2019-21 成长牛碾压）。
- **再次印证 ③**：PB 价值是**防御因子**（高 Sharpe、低回撤、熊市超额正），非跑赢宽市场的 long-only 收益引擎。

**下一批方向（5-10）**：5 趋势闸过滤价值陷阱（close>sma 硬过滤，非 tilt）；6 ROE>0 价值陷阱过滤；7 deeper value_frac=0.1；8 PE 价值；9 regime 择时价值（市场弱时减仓）；10 纯低波动独立异象。

**迭代 5-10 关键发现**：**慢调仓（季频 reb=60）是最大杠杆**——价值是慢信号，reb 20→60 让 2019-21 超额 −0.52→−0.004、全程超额 −0.50→−0.08、maxDD 0.19→0.12。ROE>0 过滤 + 慢调仓 + 宽篮三要素皆改善风险调整。趋势闸/PE/低波动无益或证伪。

**正向方向**：慢调仓宽价值（+ROE 过滤）≈ 防御性近基准收益、回撤腰斩——"同收益半风险"的真实风险调整 edge（非跑赢宽市场）。下一批（11-13）：reb 敏感面确认（防尖峰）+ 三要素最佳组合（ROE×慢调仓×宽）+ 显式 OOS。
