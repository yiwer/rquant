# 量化决策树迭代循环（大数据 + screen 验证台）

- 起：2026-06-16（/loop 自驱，≥10 迭代：回测→观察→思考→改树→下一轮）
- 数据：全市场 survivorship-free top-2000（`data/universe_membership.csv` 5194 + `membership_top2000.csv`），2018–2026 含 2018/2022 熊 + 2019-21 牛 + 2023-25。
- 验证台：`rquant screen --backtest`（横截面 top-N、regime 切片、优质分层、OOS 经 --from/--to）。基准 = top-2000 等权无成本；成本单边 10bps。
- 既有诚实结论（出发点）：**PB 价值是唯一有横截面预测力的基本面信号，但仅防御**（cheapest-N long-only 全程跑输宽基准、熊市超额正）；**价值+动量证伪**（动量在便宜池内前瞻为负）；质量/成长证伪；纯技术在大盘弱。
- **§5.3 纪律**：genuinely 探索、敏感面看稳健性、**不调参凑尖峰**；falsification 是有效产出。每轮记 OOS（2023-2026）超额 + Sharpe + maxDD + 2018/2022 熊切片 + 诚实判定。

## 循环最终结论（19 迭代，2018-2026 top-2000 survivorship-free）

**唯一稳健（样本内外皆成立）的结果：价值（低 PB）是防御/风控因子**——慢调仓（季频）+ 宽篮（top60-100）+ ROE>0 过滤 → 近基准收益、**回撤腰斩（~0.10-0.15 vs 基准~0.3）、Sharpe ~0.48-0.55**。价值的价值在"少亏"不在"多赚"；OOS 仍 lag 收益但保持低回撤（防御属性泛化）。

**全部证伪/未通过 OOS**：
- 纯技术/趋势横截面选股（动量/低波/反转/MACD/道氏理论/price-action 突破/时序均值回归）→ **灾难证伪**（Sharpe 负、回撤 50-89%）；这些选高位/落刀股后崩。
- 二级技术 tilt 叠加价值（动量/低波/反转）→ 一律恶化（浓缩+换手+噪声）。
- 价值+短趋势(60MA)/自创结构闸(道氏higher-low/波动收缩)→ 未胜纯慢价值。
- **价值+长趋势(250MA)→ 全样本跑赢但 OOS 稳健证伪（regime 依赖于 2019-21）**。
- 质量/成长（子项②）、价值×动量（子项③）→ 已证伪。

**大方向终判**：A 股 top-2000 上，**价值（PB）是仅有的真信号，其稳健可用形态是防御/风控（低 PB+ROE 篮少亏），而非跑赢宽市场的 long-only alpha**；所有纯技术/趋势信号作横截面选股均不成立；任何全样本跑赢配置都未过 OOS（regime 依赖）。**可部署候选 = `value_roe_v1` 或 `value_lt_roe`（防御口径：慢调仓宽价值+ROE）作风控 overlay，非超额工具。** §5.3 全程上守：未调参凑数，OOS 证伪了诱人的全程 winner。

## 迭代 26（用户新方法学轴：每日尾盘调仓的横截面"选股"框架）

**用户指令**：改用"每天快进快出、尾盘调仓一次"的方式，**聚焦选股**，并**构建该策略的回测-评估-Claude优化循环框架**。

**先验证引擎（逐行）**：`--rebalance 1` → 每个交易日一个调仓段 `(T,T+1)`，段收益 = `close[T]→close[T+1]`，即忠实建模"尾盘决策+成交、持有1日"；打分无前视（`trailing_visible`≤t + 基本面 `as_of(t)`，有 `no_future_bar_leaks_property` 测试）；成本 `nav*=1−(cost_bps/2/1e4)·Σ|Δw|`，满仓全换=cost_bps个bp。单次全样本日频回测 ~100s，循环可跑。**执行时点诚实声明**：模型在同一收盘价决策+成交，略乐观于现实"T决策/T+1成交"。

**交付框架三件套**：① 纯信号选股配置约定（信号作 quality、λ=0 → combined=quality、select_top 直选）；② `scripts/daily_eval.py`（一次跑 gross/net 双档，输出换手/毛净超额/Sharpe/回撤/**成本衰减/break-even成本**/各regime/**诚实裁决**）；③ 判读准则（毛超额>0 源头闸 + 净 OOS 超额>0 且净Sharpe>0 金标准 + 跨参数不翻号 + break-even≥2×真实成本）。
