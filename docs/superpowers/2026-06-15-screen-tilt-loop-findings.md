# 选股器迭代循环（#2–#6）发现（诚实记录）

- 日期：2026-06-15
- 范围：自驱循环（/loop，≥5 次），目标"重定义优质 / 转动量驱动，回测—迭代—再回测，直到足够优质"。在深 20 universe（2018-2026）上跑。
- 结论一句话：**找到唯一正超额配置（top=10, reb=5, 快动量）= +23pp 跨 regime 正——但它是参数空间里的尖峰过拟合点（top 或 reb 任一扰动即翻负），非稳健 edge。诚实判定：动量驱动选股在这 20 只大盘上无稳健超额；按 §5.3 停止，不追尖峰。**

## 2. 关键发现：尖峰过拟合

唯一跑赢基准的配置是 **(quality=趋势过滤, momentum=mom20, top=10, reb=5)**：total +323% vs 基准 +300%，超额 +23pp，**且 2019-21 牛/2022 熊/2023-24 三 regime 超额全正**（+4.6/+15.4/+4.3pp）、Sharpe 0.86。

但**任一参数邻域都翻负**：
- rebalance：5→正，10/20→负；
- top-N：10→正，5/15→负。

两维双侧邻域都击穿 = **局部尖峰而非平台**（WFO 方法学里的典型过拟合红旗）。跨 regime 时间维正、参数维双侧脆 → 这是恰好落在尖峰上的乐观，不是稳健 edge。

## 3. 诚实判定

- **动量驱动选股在这 20 只大盘上没有稳健的超基准 edge。** 唯一正配置是过拟合尖峰，扰动即失。
- **按 §5.3 停止**：继续在 (top,reb,lookback) 空间里搜更"好看"的点 = 追尖峰 = 曲线拟合，与诚实文化相违。≥5 次已满足，方向已判清。
- **隐约的弱信号**：尖峰恰好跨 regime 正，暗示存在一个微弱、不易稳健捕获的动量效应——与既往结论（强度树条件 edge 但 Sharpe 腰斩、动量标签 +0.27% 弱正）一致。

## 4. 跨四阶段收敛结论（强化）

Phase-1（AND 空仓）+ 迭代#1（优质驱动坍缩）+ 深重验（4 棵树）+ 本循环（动量驱动尖峰）四者一致指向：**这 20 只大盘 + 纯 OHLCV 技术信号，难以稳健跑赢等权买入持有**。要实质突破，方向应是换信号族（基本面——但本引擎 OHLCV-only）或换 universe/问法，而非继续调技术择时参数。**或接受选股器定位为风险调整/防御工具**（尖峰配置在 2022 熊确实少亏 +15.4pp），而非超额收益工具。

## 5. 机制 vs 方法学（重要区分）

- **机制完好**：screen/backtest（标签归因/regime/优质分层/可配 combine）+ combine v2（优质驱动+倾斜，lambda/tilt_setups 数据驱动）已实现、测试（354+89 零失败）、clippy --workspace 干净、可复用。本循环全程靠它快速试错（6 次迭代 < 1 会话）——这正是 Phase-1 建"历史回测+迭代机制"的价值兑现。
