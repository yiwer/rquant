### §4.3 裁决

```
学习权重 OOS (-0.195) < 等权 OOS (+0.038)
学习权重 ❌ 未超过等权 / 未过闸
```

**主要原因分析**：
1. **高换手耗尽 edge**：学习权重平均单边换手 34.9%/调仓（等权仅 8.2%）。在 20bps 成本下：34.9% × 2（双边）× 20bps ≈ 14bps/调仓，全年约 34 个调仓周期即 ~476bps 成本。而毛超额仅 +107.4%（全样本），OOS 毛超额更弱。
2. **L1 稀疏性导致评分扁平**：大多数权重为零或接近零，排名相近标的的评分差异极小，导致每轮 top-3 变化剧烈。
3. **IC 量级太小**：所有因子单因子 IC ≤0.046，线性组合提升有限，即使 OOS IC 正确也无法抵消换手成本。

| 检项 | 结果 |

**小偏差来源**（预期内，非 bug）：
- Rust 引擎：t+1 开盘起的 N-bar 前瞻收益 + `1/(1+close/bps)` 权重变换
- Python 回测器：close-to-close 5 日收益 + 排名评分
- 时点财务/票池略有差异（Rust universe 与 Python panel 重合度 ~90%+）

**注**：两者都显示 value_pb 在 OOS 2024-26（vs CSI300 口径）为负超额，与等权基线的 +0.038 相比很差。这说明单纯 PB 价值在该 OOS 窗无效，等权基线的 +0.038 主要来自 value+npyoy 的协同效应。

## §6 边界与注意事项

1. **单一 OOS 窗口**：2024-01 .. 2026-06 仅约 2.5 年，统计功效有限，结论不宜过度泛化。
2. **幸存者偏差（残留）**：membership_top2000.csv 为月末快照，月中退市股仍可能被选到（与冠军策略同口径，已知 caveat）。
3. **周频 edge 薄弱**：spec 已知"等权 reb20 OOS +2.68 → reb5 +0.10"，周频换手天然吃掉 edge。等权 OOS +0.038 已接近盈亏平衡，进一步学习的空间极小。
4. **因子共线性**：价值族（f_bm, f_roe, f_gm）彼此高相关，L1 会任意归零其中几个。报告相关矩阵超出本版范围（§5.3 不要求）。
5. **参数选择非前视**：α 由 train 窗内部切验证（2018-2022 拟合 / 2023 验证）选定，OOS 2024-26 完全未参与选 α。
6. **f_npyoy 负权重**：实际经济含义值得深究——可能是在 top-3 集中策略下，高增速股已被定价（追价效应），需要更精细的截面分析验证。

## §7 代码修复记录

本次运行发现并修复了两个 bug（已提交）：

1. **`build_factor_matrix.py` 性能 bug**：`members_at()` 每次调用都从 DataFrame 重建 set，O(N×M) 复杂度（N=1073 符号，M=410 调仓日）。修复：预计算所有快照日期的 membership dict，从 ~77 分钟降至 ~90 秒。

2. **`f_secmom` 全 NaN bug**：kday "time" 列含时间戳后缀（"2018-01-02 15:00:00"），pa_sector_merged "date" 列为纯日期（"2018-02-01"），字符串合并失败导致所有 f_secmom 为 NaN。修复：合并前均截断为 YYYY-MM-DD 前 10 个字符。

## §8 下一步建议

基于上述发现，要让学习权重超过等权，需要：

1. **降低换手**：加约束（例如在优化目标中加换手惩罚项；或直接限制每轮持仓变化 ≤1 只）
2. **月频口径**：切换到 reb=20，换手降至可控水平（参照等权 reb20 OOS +2.68 的空间）
3. **IC 更高的因子**：当前 13 因子 IC ≤0.046；引入日历效应、分析师修正、北向资金等可能提升信噪比
4. **集成方法**：用学到的因子作为 quality_tree 评分进 Rust 引擎（而非独立 top-3），利用价格行为树过滤入场时机，降低换手
5. **多折 WFO**：单切 OOS 窗约束太弱，walk-forward 可更可靠估计泛化能力
