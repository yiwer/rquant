# 换框架重测：价值选股 vs 可交易基准 — harness 里程碑发现

> 迭代 harness round 4 + 多基准/洁净窗复核（2026-06-18）。用户决策"换框架重测"后得。
> **一句话**：此前 ~30 轮"价值证伪"主要是**基准选错**——对**不可投资的等权全集**(EW +442%)衡量价值确实落后；
> 但对**可交易宽基指数**(CSI300/500/1000，2018-26 仅 +21~36%)衡量，**最便宜 PB 价值选股稳健大幅跑赢、且 OOS 成立**。
> 这是整条研究弧线**第一个可部署的正结果**。§5.3 全程上守：已做基准/规模/洁净窗/敏感性多重证伪未倒。

## 1. 背景：基准是全部分歧

screen 引擎的内建基准 = **universe 等权(EW)、无成本、逐日再平衡**。在 ~1073 流动核心上，该 EW 基准
2018-2026 累计 **+442%**——但它**不可投资**：等权 1073 名（含微小票）逐日调仓，靠的是高波动小票上的
"再平衡溢价"+ 巨额隐性冲击成本，真实世界无法复制。一个真实投资者的对手盘是**可买到的指数 ETF**。

抓 3 只宽基指数（baostock，不复权）作可交易基准：

| 指数 | 2018-01..2026-06 累计 |
|---|---|
| CSI300 沪深300（大盘） | **+22%** |
| CSI500 中证500（中盘） | **+36%** |
| CSI1000 中证1000（小盘） | **+21%** |

所有 cap-weighted 指数 8.5 年仅 +21~36%（A股大盘指数近乎走平）；EW 全集 +442% 是不可投资的统计幻象。

## 2. 结果：最便宜 PB 价值（`value_pb`，top-50，net 20bps）

策略绝对表现：**净总收益 +324%**（洁净窗 2019-05 起 +401%）、绝对 Sharpe **1.13**、最大回撤 **0.19**、
单边日换手 **2.4%**（极低，可投资）、break-even 成本 **164bps**（=8×真实成本，安全垫巨大）。

**超额（vs 各可交易指数；train 2018-01..2023-12 / OOS 2024-01..2026-06）**：

| 基准 | net 总超额 | train | OOS |
|---|---|---|---|
| CSI300 | +2.96 | +1.17 | **+0.64** |
| CSI500 | +2.85 | +1.16 | **+0.55** |
| CSI1000 | +2.97 | +1.19 | **+0.64** |

- **三个规模桶全胜**——包括**小盘 CSI1000**（超额最大）。若只是小盘 beta，绝不可能跑赢小盘指数 → **非规模 beta**。
- **Tier-2 敏感性**：top∈{30,50,100}×reb∈{1,5} 净超额 `[2.1, 2.31, 2.96, 3.82, 3.24, 4.01]`，**全正、无符号翻转**。
- **裁决 PASS**：毛超额>0 且 净 OOS>0 且 净 Sharpe>0 且 break-even≥40bps 且无符号翻转，**全满足**。

**洁净窗复核（去除 2018 无基本面空仓期；基本面首报 2019-04）**：

| 窗口 | 策略 | CSI300 | 超额 |
|---|---|---|---|
| clean-train 2019-05..2023-12 | +147% | **−7%** | **+1.53** |
| OOS 2024-01..2026-06 | +103% | +40% | **+0.64** |

2019-2023 CSI300 **为负**（成长龙头茅台/宁德 2021 见顶回落），而最便宜价值（银行/SOE）+147%——
**真实且巨大的价值-成长背离**。去掉 2018 无数据期后超额不降反升 → **2018 空仓伪影不是边的来源**。

## 3. 次优可部署变体：`value∩quality`（Greenblatt，质量地板）

便宜 30% PB 池内按 ROE 取 top-50：vs CSI300 超额 +1.71（OOS +0.16）、Sharpe 0.72、回撤 0.275、换手 3.6%。
**也过所有指数基准但更薄**——质量地板降低了收益（与 round 3 同源：ROE 浓缩大盘价值反拖累），
但**单票更安全**（过滤亏损/价值陷阱）。部署取舍：纯 `value_pb` 收益高但含距损价值陷阱风险；`value∩quality` 稳健但收益低。

## 4. 诚实边界（§5.3）

1. **结论完全取决于基准口径**：vs 不可投资 EW=证伪；vs 可交易指数=大胜。指数是**诚实的可投资对手盘**
   （EW 高估了机会成本），故此翻转合法——但必须明说："跑赢你能买到的（指数 ETF）"，非"跑赢理论 EW 组合"。
2. **regime**：2019-2026 是 A股**价值/红利友好大周期**（中特估、银行、高股息）。边在 train+OOS 均成立，
   但 OOS 是**单一价值友好宏观期**；跨多周期更长 OOS 才能进一步证实。
3. **long-only 价值/beta 溢价，非对冲 alpha**：有股票 beta，回撤 0.19 真实存在；非市场中性。
4. **最便宜 PB 含价值陷阱/距损票**：部署应加质量+流动性地板（`value∩quality` 方向），牺牲部分收益换稳健。
5. **执行口径**：close[T] 同时决策+成交（略乐观；真实 T+1 开盘）。survivorship-free ✓ + point-in-time 基本面 ✓ + 净成本 ✓。

## 5. 方法学产出（可复用）

- **`scripts/fetch_index.py`**：抓 CSI300/500/1000 → `data/baostock/index/`（gitignored）。
- **`scripts/iterate.py --benchmark csi300|csi500|csi1000`**：引擎零改动的**指数相对超额**评估器
  （`to_index_relative` 从 screen JSON 的 nav 曲线 + 指数序列重算超额，full+各 regime；绝对 Sharpe 透传）。
  指数相对超额可对**任一已存 run 的 nav 曲线后验计算**（无需重跑），故多基准复核近乎零成本。

## 6. 前瞻（用户定夺）

- **部署候选**：`value_pb`（高收益）或 `value∩quality`（稳健）作 long-only 价值组合，月/季频调仓（换手已低），
  对标 CSI300/500 ETF。需：质量+流动性地板、真实 T+1 执行、容量/冲击成本评估、跨周期纸面盘跟踪。
- **加固**：把指数基准固化进 screen 引擎（当前仅 harness 后验）；更长/多周期 OOS；行业中性版（剥离行业集中）。
- **harness 续轮**：其余技术/微结构角度（队列）在 EW 与指数两口径下大概率仍证伪——价值是迄今唯一稳健正边。
