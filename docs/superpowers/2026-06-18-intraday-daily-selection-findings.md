# 日内(15m)特征驱动尾盘日频选股 — findings

> 执行 spec `2026-06-18-intraday-daily-selection-design.md`（用户 greenlight）。诚实文化 + §5.3：本轮最大价值是**一个被诚实闸抓住的幸存者偏差陷阱**——若不做合理性检查，会误报"日内 alpha 发现"。

## 结论（一句话）

在**点时无偏** universe 上，**6 因子 × 正反两向 = 12 个日内选股器全部证伪**（净超额 ≤ +0.02 且时间二分不一致）。日内微结构特征在此 6mo 窗口对次日横截面选股**无净 edge**。与 27 轮日频日线选股结论同源。

## 关键过程：survivorship 陷阱与如何抓住它

**初版（biased）**：试点 universe 按**当前(2026-06)成交额**取 top-180 → 实为"按窗口末流动性选股"，前视性地选中了涨进 2026-06 的赢家。后果：
- 基准(EW) **+102.7% / 6mo**、最大回撤 ~8%、年化 Sharpe **8–18**；3 个因子(intraday_range_hi 净+0.62 / overnight_hi 净+0.18 / close_vs_vwap_hi)"未证伪"。
- **合理性检查触发警觉**：大盘 EW +103%/6mo + Sharpe 18 物理上不可信。诊断：
  - 真大盘股(招行−4%/茅台−8%/平安−12%)正常 → 非全局数据错。
  - 全 universe 买入持有 median **+74%**、max **+710%** → 异常来自 universe。
  - 逐股查跳变：**0 只 >30% 单日跳**，+700% 全是合法连板(≤20% STAR/≤10% 主板)+ 放量 → **真行情(题材妖股连板)，非拼接伪影**。
  - 定位：**universe 用窗口末流动性选股 = 前视幸存者偏差**（赢家涨上去→成交额大→被选入）。

**修正**：universe 改**点时**（`build_intraday_universe.py --asof 2025-12-09`：用 ≤2025-11-28 membership 快照 + 窗口前 20 日成交额排名）→ 剔除窗口内前视。点时 universe 买入持有 mean +23% / median **+5.3%** / max +274%（基准 EW +19.6%，合理）。

## 诚实局限（spec 已预警，本轮坐实）

1. **6 个月单一 regime**（且是题材妖股大年）→ 无 OOS，年化 Sharpe 不可信（biased 跑出 18 是反面教材）。
2. **幸存者偏差**：sina 不供退市/停牌 15m，只能测窗口内存活股。
3. **daily_eval 裁决偏松**：仅查"净 OOS(后半)超额>0"，不查净总超额 + 前后半一致 → 会把 biased 的 3 个伪 alpha 判 PASS。**本 findings 用 spec 严格闸（前后半同号 + 净总>0）**，更稳。建议后续把严格闸固化进 daily_eval（backlog）。

## 终判

**日内特征日频选股在可得数据(6mo/sina/幸存者)上证伪、且无法 OOS 验证。** 本轮真正价值：①交付了完整可复用的日内→日频选股管线；②**合理性检查抓住了一个会产生假阳性的 survivorship 陷阱**——正是诚实文化的意义。与全部 27 轮日频结论一致：A股 top 流动股上，技术/微结构横截面选股跑不赢等权基准；唯一稳健边仍是价值-防御(慢调仓)。若将来有**多年、survivorship-free、日内**数据，可用本管线正经 OOS 重测；当前 EV 低。
