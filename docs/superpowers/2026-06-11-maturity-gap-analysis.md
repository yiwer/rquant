# rquant 成熟度差距分析（对标成熟量化分析决策交易引擎）

- **日期**：2026-06-11
- **参照**：barca0412《Introduction to Quantitative Finance》资料库 18 领域；qlib / vnpy / vectorbt / Riskfolio / FinRL 等成熟生态
- **基线**：master `a8ad45b`，E1-E5 + HTML 补全后（四入口：硬/软打分、--sim、portfolio；195 测试）

## 结论

rquant 已是成熟的**策略表达与验证引擎**（表达=YAML 树+DSL+LLM；验证=信号打分/权益模拟/横截面组合/可视化全闭环）。距离"量化分析决策交易引擎"差**三层**：

1. **研究深度层**——你怎么知道因子/树是好的？
2. **风险组合层**——收益之外的风险语言。
3. **数据与生产层**——从"回测报告"到"明早的单子"。

## 缺口清单

### 一、研究深度层（最大短板，对标多因子框架核心）
- **F-1 因子检验工作台**：IC/RankIC、IC 衰减、分层回测（quintile spread）、因子相关性矩阵。`factors:` 块能算因子但无"因子好不好"的统计工具；现状等于用整树回测代替单因子检验（慢、归因混淆）。
- **F-2 参数寻优 WFO 闭环**：grid/random 搜索 + 滚动 IS 寻优/OS 验证 + 过拟合防护（deflated Sharpe）。`params:` 与 walk-forward 均已是入口，缺 optimizer 接环；现 wf 仅"固定树分折看稳定性"。
- **F-3 统计显著性**：bootstrap/置换检验、多重检验校正。伪概率（LLM）策略尤其需要回答"这是运气吗"。

### 二、风险组合层（最便宜，应最先补）
- **F-4 风险指标集**：年化收益/波动、Sharpe/Sortino/Calmar、VaR/CVaR、β、月度收益表。现仅 total_return/max_dd/win_rate/turnover——连 Sharpe 都没有。约半天工作量，全部报告受益。
- **F-5 组合构造升级**：波动率倒数加权/风险平价/波动率目标（等权 top-N 之上的下一档）。
- **F-6 组合级风控**：单标的权重上限、组合回撤熔断、行业暴露约束（`risk:` 块现仅在单标的 sim 层）。

### 三、数据与生产层（决定是不是"交易"引擎）
- **F-7 数据基建** ⚠️：**复权处理**（最尖锐——新浪数据若未复权，除权日假跳空直接污染信号与收益，正确性级别）、本地数据库/增量更新、多源冗余、基本面获取器（`--aux` 是注入口但无获取器）。
- **F-8 执行模型**：滑点/冲击成本（现固定 bps）、成交量参与率、涨跌停可执行性。
- **F-9 实盘通路**：`signal` 子命令（最新 bar → 今日目标持仓 diff）、paper trading、券商/vnpy 对接、调度+推送。最小可行版（signal+定时）即完成"回测工具→每天给单子的系统"的质变。

## 定位差异（明确不做）
- ML/DL/RL 预测器：rquant 的模型=树+LLM，刻意不炼丹；外部模型经 `aux.model.score` 注入（标准 pattern，应写入文档）。
- HFT/L2 微观结构、加密货币：定位外。

## 优先级路线（价值/成本排序）
1. **F-7a 复权口径验证**（先查，决定一切数字可信度）→ **F-4 风险指标集**
2. **F-1 因子检验工作台**（复用 factors + forward_return 机件）
3. **F-2 寻优 WFO 闭环**
4. **F-9 最小实盘通路**（`signal` 子命令 + 调度）
5. F-5 / F-6 / F-8 渐进增强

## F-7a 验证结果（2026-06-11 实测）：**确认不复权，正确性问题成立**

方法：拉高股息标的 4 年日线（`fetch --scale 240`，顺手修了日线 date-only 解析 bug `978fd0c`），扫隔夜跳空（`open/prev_close−1 < −2%` 且日内近平 = 除息缺口）。

- **sh601398 工行**：2022-07-12 `−5.64%`、2023-07-17 `−5.54%`、2024-07-16 `−4.52%`、2025-01-07 `−2.07%`（中期分红）——每年 7 月精准 ≈ 股息率。
- **sh601088 神华**：2022-07-11 `−10.31%`、2023-07-05 `−8.13%`、2024-07-08 `−5.10%`、2025-07-07 `−5.51%` + 每年 3 月中期分红跳空——双重分红全部裸露。

**结论**：新浪 getKLineData 返回原始价（不复权）。影响：① 除息日假跳空触发假信号（crossunder/动量/止损）；② 分红计为亏损 → 高股息策略被系统性低估（神华年化 ~10%！）；③ 既有真数据 smoke 的 buy&hold 对照偏悲观。**修复（复权数据通路）优先级提升至 F-4 之前。**
