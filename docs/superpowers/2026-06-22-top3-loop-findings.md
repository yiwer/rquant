# top-2-3 选股策略自驱迭代 loop — findings

> 用户 /loop（动态自驱）："初始先遗忘之前所有的猜想，构建适合 top2-3 的几个初始选股策略 → 回测 → 观察 → 优化 → 再回测，loop 100次"。
> 诚实立场：**忘记结论先验、保留方法学纪律**（无前视 + 真 train/OOS + §5.3 闸）。目标 = **可投资 top-3**（用户资金/手续约束，仅持~3 只）→ 生存者用地板闸过滤可成交名。
> 跑法：5 fire / 28 轮（账本 r66-93），daily 轴(universe_baostock_day 3000+ 股，train2018-23/OOS2024-26)，月频 reb20，net@20bps，vs csi300（主）+ vs-EW（参考），PASS 触发 tier2(top30/50/100×reb1/5)。

## 结论（一句话）

**忘记先验、广扫 11 类策略后，找到一个比已部署三核更强的可投资 top-3 冠军：「价值 + 净利增速」(value_pb + np_yoy) 地板闸**——投后 OOS +0.79(reb20)/+0.44(reb10)、Sharpe **0.96**、maxDD **0.24**、tier2 +1.7~2.7 全正无翻转、top-2 +0.34，**约为已部署三核(value+营收增速+毛利)可投资 top-3 (+0.27) 的 3 倍**。核心发现：**对集中 top-3，净利增速(np_yoy) > 营收增速(rev_yoy)+毛利**。

- **Fire1 scout（raw top-3，8 类）**：纯价值PB / 价值PE / 高ROE / 高营收成长 / GARP / 价值成长双核 / 多因子VQG / 动量龙头。
- **Fire2 floor**：把生存者加【盈利 roe>0 + 流动性 20日均额≥5000万】地板闸 → 可投资数；top-3 & top-2。

- **Fire4 确认**：价值+净利增速 的 reb/集中稳健性 + 优化变体 价值+净利+毛利。
- **Fire5 novel**：低波动 / 反转 / 布林均值回归（"忘记先验"的非基本面收尾扫）。

## 判读

1. **"忘记先验"有收获**：fresh 广扫推翻了"已部署三核(营收增速版)就是最优"——同框架换成**净利增速**，可投资 top-3 从 +0.27 升到 +0.79（~3×），Sharpe 0.47→0.96、回撤 0.37→0.24、且首次 vs-EW 转正(+1.69)。
2. **但仍是诚实的"小边"**：OOS +0.4~0.8 随调仓频率，季频(reb60)≈0；top-3 三名统计脆弱；单一 2018-26 OOS。它**改善而非颠覆**——价值核心仍是底座，换更优成长腿是边际增益。
3. **多因子 raw 冠军(+1.83)是陷阱**：floor 后 OOS 不变但 ablation 揭示 ROE 贡献特异(value+ROE 仅+0.02)、reb10/60 腰斩、top-2 崩到+0.02 → 尖峰非结构边，**不取**。
4. **非基本面再次全废**（动量/反转/布林/低波动 top-3 无 edge），与全程一致：A股短线/技术面横截面选股在集中口径下无稳健边。

## 续验（fire 6-7，r94-99）

- **fire6 跨调仓稳健**：毛利腿提供跨调仓稳定。**价值+净利+毛利**(vng) reb10/20/60 = +0.75/+0.70/+0.81（**季频不衰**），而 2 因子冠军 价值+净利 reb60 仅 +0.003。代价：vng reb20 Sharpe 0.53 < 冠军 0.96。四因子 reb20 +1.80/reb60 +0.69。⇒ 严格月频用 价值+净利(Sharpe 高)；若调仓漂移，价值+净利+毛利 更稳。
- **fire7 去幸存者(点时 top-2000 成分，iterate 新增 `--membership`)**：**冠军 价值+净利 不仅不塌、反而更强**——投后 OOS +0.79 → **+2.68**、Sharpe 0.96→**1.02**、vs-EW +3.85、tier2 无翻转。机制：点时 top-2000 滤掉地板闸没抓干净的残余微盘价值陷阱→更干净更投得进。**价值+净利+毛利 在 top-2000 上反降**(OOS +0.43、vs-EW −2.40)→毛利腿在大中盘池无益。⇒ **在更可投资的 top-2000 池，价值+净利(2 因子) 明确胜出，强化部署选择**。
  - 诚实caveat：universe_baostock_day 为生存者并集，membership 只能把生存者限制到其成分期（退市名数据缺失无法补回）→**部分**去幸存者；但 +2.68/Sharpe1.02 已是强稳健信号。tier2 cells 同口径(已补 membership 透传)。

## 可投资建议

- **若坚持 top-3**：用「价值+净利增速」地板闸（Sharpe0.96/回撤0.24 最优）。
- **若能放 top-2/想更稳的 top-2**：用「价值+净利+毛利」(top-2 +0.46)。
- 二者均 > 当前部署三核；**建议把部署的成长腿从营收增速换成净利增速**（已起草，待用户确认）。
- 沿用诚实边界：薄边、top-3 高波动(maxDD~24-40%)、扣费仍赢(be 237bps»真实)、单一 OOS、月/双周调仓（勿季频）。
