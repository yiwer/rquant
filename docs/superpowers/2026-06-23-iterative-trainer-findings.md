# 迭代 SGD 训练器 — 收敛确认，但诚实池不胜闭式 ridge

> 日期 2026-06-23 · 分支 iterative-trainer · 标准 §5.3
> 动机：用户完整方案（PCA 正交 + softmax 组合目标 + dropout + 多轮小步 + 退火噪音 + Polyak + per-N + 每轮持久化）；并质疑"3000 轮未收敛，加大轮次再下结论"。

## §0 收敛（用户对了）
逐轮 val_obj（softmax-组合，跨折均值）：r100 −0.02 → r2000 **−0.18(谷)** → r5000 −0.14 → r10000 −0.04 → **r15000 +0.006 → r20000 +0.004（平台/微降）**。
**3000 轮确实未收敛；~15000 轮才到平台、且平台仅 ~0（break-even）。** 退火噪音使收敛后载——印证理论。

## §1 OOS 裁决（membership 权威池，20000 轮收敛后）
N=2 逐折：iter [+0.030, −0.301, +0.268, **+5.597**] 均值 +1.398；ridge [+0.193, +0.132, +0.001, +0.560] 均值 **+0.222（4/4）**。
- **ridge membership +0.222 精确复现 eval_ridge 权威值 → harness 一致。** 4/4 折全正、均衡、无单折依赖。
- **iter +1.398 完全靠 2025-26 单折 +5.597**（单只 ~10x 股被 top-N 集中抓到=彩票）。**去 2025：iter ≈ −0.001（N=2）/ −0.060（N=3）、2/4 折、§5.3-False。**
- 先前"iter +1.93 vs ridge +0.66 BEATS"混入 **full 宽池幸存者偏差**（ridge 那里 +1.10 ≠ 诚实 +0.222）；不可信。

## §2 理论验证（见 2026-06-23 对话的优化器分析）
- 收敛的 SGD → 隐式早停正则消失 → 落到（弱的、信号受限的）显式-λ 最优；val 平台 ~0、r15000→20000 微降（过拟合苗头）。**对闭式 ridge 无真实增量。**
- SGD"更不过拟合"的名声来自早停隐式正则（被"求收敛"抵消）+ 非凸平坦极小（本低维问题不具备）；dropout/装袋是真正则但优化器无关（ridge 装袋已测 ≈ ridge）。
- **过拟合上限由有效样本（~一手 regime）+ 信号弱（组合 IC≤0.066）决定，非优化器。**

## §3 结论
- **ridge-on-gauss +0.222（4/4 干净）仍是 deploy-candidate**；迭代 SGD 即便收敛、诚实评估也不胜它，"胜"是 full 池幸存 + 2025 单折彩票双重伪影。
- 用户的**收敛质疑有效**（3000 不够、~15000 才收敛），方法论正确；但结论是闭式 ridge 在凸组合器上已是上界。
- **关于"强制因子独立"**：破墙的 ridge 用的是**原始相关 gauss 因子（无 PCA）**；迭代器加了 PCA 正交化反而更差。PCA 无监督（方差≠预测）+ 95% 截断丢低方差预测方向；**让正则化 ridge 原生吸收相关 > 强制独立**。
- 部署不动。复用：train_iterative.py（迭代器 + 每轮持久化 + 收敛分析）。

## §4 边界
- 单一窗族（4 折 2022-2026H1）；2025-26 折最长（18 月）且含大牛股 → top-N 集中放大成彩票。
- 迭代器评估同时跑 membership + full；full 含幸存者偏差，绝对值不可信。
