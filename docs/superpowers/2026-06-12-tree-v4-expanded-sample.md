## v4 结构变更（相对 v3）

1. **自适应波动闸**：固定 `vol_floor/vol_cap` 绝对阈值 → `percentrank(vol_ratio, 60)` 滚动百分位（`q_vol_lo/q_vol_hi`）。固定阈值是跨标的/跨周期最脆的部位；自归一化后 60m↔日线免重校。窗口算术保证决策点恒有值（A6 注）。
2. **参数门控 Turtle S1**：四个突破入场漏斗加 `s1_on > 0 and last_trip_return > 0 → flat_s1_skip` 阻断分支——S1 的开关进 WFO 网格，由 WFO 自己完成归因。

## 矩阵 A/B（v3 定参 vs v4 初始 q_vol_hi=0.95，40 sim）

- 回撤：v4 在 **17/20** 样本更低（000333d 15.2→7.7、300750d 21.9→14.9、601088h 10.4→4.9）。

- 结论：闸门形态对，**上限参数过紧** → 交给 WFO。

## 组合层部署形态验证（10 标的 universe top-3）

硬遍历：平均持仓成员 **0.20/3**（日线）——触发型树在固定调仓日横截面打分几乎全 flat，组合长期空仓；软模式提升到 0.5/3 仍稀疏。日线软组合 Sharpe 0.48 但跑输等权基准 11pp（牛市样本）。
**架构级结论**：本树是事件/触发树，与"横截面取 top-N"的连续打分形态错配。v3 报告的"部署走组合层"方向仍对，但需要**为横截面单独设计持续型强度树**（v5 方向），而非复用触发树。

## 诚实判读

1. **仍不构成生产 go**：严格 OS 证据限于 030/036 两只（+1.15/+0.96）；其余为负或部分样本内。
2. 扩样三大产出：**证伪 858**（短样本幸存者）；**确认 030 为双周期 edge 标的**；**S1 与波动闸形态完成归因定型**。
3. 策略身份明确：**低回撤绝对收益型触发策略**——16/20 样本回撤 ≤5%，牛市捕获率低是本性不是缺陷（吊灯+regime 闸的代价）；适合做组合里的防守腿而非 beta 替代。
4. v5 方向：横截面持续型强度树（组合层适配）；030/036 双标的 signal 纸面盘试运行（已具备 OS 证据的最小部署）。
