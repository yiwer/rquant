# 三个 top-3 集中持仓策略 对比 — findings

> 执行 plan `plans/2026-06-21-top3-concentrated-strategies.md`（子代理驱动 T1-T3）。
> 用户需求：3 个「平均持仓前 3」策略对比 —— S1 纯价值三核 top-3；S2 价值初筛~30 → 1h-K×100根 PA 强化 → top-3；S3 行业强度初筛 + 价值深度加权 → top-3。
> 诚实文化 §5.3：每策略同时报 **top-3（用户目标）与 top-10（稳定性参照）**，并补一条 **top-50 同轴基线**，避免把运气当 alpha。

## 结论（一句话）

**纯价值（S1）在 top-3/10/50 上全部稳健跑赢 csi300；1h-PA 强化（S2）与板块强度深度加权（S3）在任何集中度下都被证伪。** 价值核心是唯一稳健边；任何短线/板块倾斜都把它的低换手优势churn 掉、净 OOS 翻负。**集中到 top-3 仍能跑赢，但风险调整后劣于 top-10/50**——集中不增益，只加噪声。

## 判读

### 1. 价值尖兵(S1) — 部署级稳健边，集中度全谱系成立
top-3/10/50 净 OOS 全部 ≥+1.40、Sharpe ≥0.75、break-even ≥337bps、tier2 无翻转。这是迄今最强的可投资结论：**纯价值三核在月频、可交易宽基(csi300)上稳健跑赢，且对持仓数(3~100)极不敏感**。vs-EW 也全正(net +2.38~+3.42)——非基准伪影。

### 2. 集中"不增益"——诚实更正
同轴(daily/reb20)集中度阶梯：Sharpe **1.09(top50) → 1.00(top10) → 0.75(top3)**，净 OOS **+1.92 → +1.63 → +1.40**，maxDD 与换手随集中**单调变差**。即 **top-3 仍 PASS，但风险调整后是三档里最弱的**；集中只加个股特异风险、不加 alpha。
> ⚠️ 自我更正：首轮我曾把 r57(top-3, +1.40) 对比旧 r55(top-50, **reb5/paov 轴** +0.28) 误读为"集中放大 5×"。补了同轴 top-50 基线(r63 +1.92)后真相相反：那 +0.28 是**周频 reb5 + paov 轴**的代价，与持仓数无关；月频 reb20 的价值远强于周频。集中本身略降质。

### 3. 价值盘口(S2) / 板块价值(S3) — 短线/板块倾斜 churn 掉价值边
- **换手爆炸**：价值 15-26%/日 → S2 **78-88%/日**、S3 **72-74%/日**(3-5×)；maxDD 28-35% → **51-64%**。
- **break-even 崩塌**：价值 337-567bps → S2 **38-39bps**、S3 **19bps**——成本容忍度跌 90%+，扣费即死。
- **train 正 / OOS 负**典型过拟合：S2 train +0.77 → OOS −0.12；S3(top10) train +0.41 → OOS −0.55。1h-PA 排序 / 板块强度倾斜在样本内像信号、样本外是噪声。
- **机制**：与全程一致——价值定"买什么"(慢、低换手)是边；任何"短线择时/板块轮动"倾斜都把它推向高换手高回撤，正交性原理第 N 次兑现(PA/板块个体无 edge → 混入只稀释)。

## 一致的元结论（四轮证伪后定论）

横截面**选股或倾斜**层面：
- ✅ **价值-防御、慢调仓(月频)、适度分散(top-10~50)** = 唯一稳健边(vs csi300，net-OOS +1.6~+1.9，Sharpe~1.0)。
- ❌ 任何**短线/技术面/板块**因子(15m 选股 r1-43、FF3 r49-50、PA+板块 overlay r51-56、本轮 1h-PA 强化 + 板块深度加权 r59-62)在横截面上**无增益、且通过抬换手抬回撤主动毁边**。

**唯一仍未穷尽的短线路径** = 「持仓内逐 bar 真择时」(signal/sim 引擎，调仓选股之外的进出场时机)——本轮范围外，是下一个可证伪方向。

## 诚实边界

- **top-3 统计脆弱**：3 名个股，+1.40 OOS 可能受 1-2 只主导；但 top-10/50 同向且更强(无翻转)证明价值边非 3 名运气——脆弱的是"集中"，不是"价值"。
- S2/S3 用 csi300(可交易)为主裁；vs-EW(2963/3052 等权小盘 beta，不可投资)仅参考。
- 单一 2018-26(S2 为 2021-26)OOS、long-only beta、T+1、幸存者偏差沿用并标注。
- **可投资建议**：用**价值三核**(慢、月频、top-10~50 分散，vs 指数稳健)；若坚持 top-3 集中，仍跑赢但接受更低 Sharpe / 更深回撤；**勿加** 1h-PA 强化或板块强度倾斜。
