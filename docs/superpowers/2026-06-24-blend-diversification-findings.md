# 策略多元化 — 「岭值双引擎」(去相关岭组合 × 价值净利双核)

> 日期 2026-06-24 · 分支 blend-diversify · 标准 §5.3
> 动机:gauntlet ① 显示两个**已各自验证**的 edge 在 regime 上互补(ridge 下行年大胜、价值在轮动/牛年更猛)
> → 假设两者**低相关**,合成可在不凑参的前提下改善风险调整收益。"分散是唯一免费午餐"。

## §0 方法（`scripts/eval_blend.py`）

同一套 weekly top-3 / membership / 成本 / 迟滞 harness,**只换打分**:
- ridge = `norm_gauss(72因子) @ w_ridge`(+ 选定 delta)= 去相关岭组合
- value = `rank(f_bm)+rank(f_npyoy)` top-3(delta 0)= 价值净利双核基线
逐 OOS 折由各自回测 NAV 还原 weekly 净收益序列,测相关 + 对比**固定 50/50 收益合成** vs 各自单独的
年化 Sharpe / 最大回撤 / csi300 超额。**无参数搜索**——单一预设 50/50(最小方差最优权重仅作信息打印)。
harness 自洽性:ridge 均值超额 +0.186、value +0.080 与 gauntlet ① 逐字吻合。

## §2 判定 —— 多元化"抗回撤"路径成立

- **合成 Sharpe 0.68 = 单独 ridge(并列最优),但最大回撤 0.24 → 0.17(−29%)。** 同等收益效率、更平滑。
- 超额 +0.145 介于两者、偏 ridge;**没有牺牲多少收益换来的回撤改善**。
- regime 互补真实:**2022 熊 ridge 扛(val −0.068)、2021 轮动 val 扛(ridge +0.134)**——合成两头都不踏空。
- corr +0.36 是**中度正相关**(非负),所以收益不叠加、但波动/回撤被摊薄 → 收益持平、风险下降。
- 诚实边界:合成 Sharpe **未超**最优单腿(并列),"赢"在回撤与稳定性,不是更高收益。50/50 为预设非寻优;
  最小方差权重 0.44 与之接近(无过拟合嫌疑)。

## §3 结论

- **「岭值双引擎」= 去相关岭组合 + 价值净利双核 50/50** 是比任一单腿更优的**风险调整部署形态**(同 Sharpe、−29% 回撤)。
- 这是全弧首个**多策略**改进,且**不加因子、不凑参、复用 vetted 原语**——与"因子已饱和、edge 在组合器"一致:
  下一层 edge 来自**策略间分散**,不是单策略再优化。
- 复用 `eval_blend.py`。**部署不动**;是否把实盘改为双引擎(或纸面盘加一条 value 腿对照)是用户的决定。
