# 选股器 Phase 1 验证发现（诚实记录）

- 日期：2026-06-15
- 范围：在深 20 标的 universe（`data/universe_20.csv`，2018-2026）上验证选股器种子集成方法学。
- 结论一句话：**Phase 1 机制（选股 + 历史回测 + 标签归因/regime/优质分层 + 迭代工具）已建成并可用；但种子集成作为可用选股器被证伪——失败模式明确且有信息量。**

## 2. 诚实诊断

**核心病灶 = 长期空仓（avg_members 0.38）。** top=10 的容量下，平均每次调仓只选出 0.38 只——即**绝大多数调仓点持现金**。在 2019-2021 的大牛市里，等权基准满仓吃到 +300%，而选股器几乎空仓踏空 → 绝对 −42% 主要是**机会成本**（不是 picks 亏钱，是没仓位）。

**为何长期空仓——不相交集合问题：**
- 入选要求 `优质≥0.5` **且** 至少命中一个形态标签（综合分 = 优质 × 投机，二者缺一则 0）。
- 优质（稳健上升趋势）与投机形态（动量/突破/超跌）**很少同时出现**：稳的不动、动的不稳。强 AND 交集把候选池打到几乎为空。
- 全历史 7120 个「标的×调仓」里只有约 158 次形态触发（~2.2%），再与优质门求交 → 几乎选不出东西。

**信号级归因（每形态 picks 前瞻收益）：**
| 形态 | picks | 胜率 | 均前瞻收益 |
|---|---|---|---|
| 动量延续 | 116 | 0.48 | **+0.0027** |
| 突破临界 | 31 | 0.55 | −0.0048 |
| 超跌反弹 | 11 | 0.45 | −0.0057 |

只有**动量延续弱正**（与上轮深重验「横截面强度/动量是唯一显 edge 方向」一致）；突破临界、超跌反弹净负且样本稀少。

**优质分分层（优质轴是否预测前瞻收益）：** Q1(质0.74)+0.0031 / Q2(质1.0)−0.0096 / Q3(质1.0)+0.0120 —— **非单调、不结论**（合格样本太少，质量近二值）。优质轴在此样本上未显示干净的预测力。

**regime 切片：**
- 2019-21 牛：picks −0.31 vs 基准 +2.73 → 超额 **−3.04**（空仓踏空牛市，致命）。
- 2022 熊：picks +0.00 vs 基准 −0.27 → 超额 +0.27（**靠空仓"跑赢"，非选股能力**）。
- 2023-24：picks +0.03 vs 基准 +0.19 → 超额 −0.16（跑输）。
- 2018 熊：未覆盖（数据始于 2018-01，被 ema200 预热消耗）。

## 3. 诚实立场（§5.3 纪律）

**未对阈值/树做任何"调到好看"的改动。** 负结论是有效产出——它在投入 Phase 2（广度拉取 + 日频运行 + 桌面页）之前，廉价地证明了种子方法学（优质 × 投机的强 AND 交集）不可用。这正是分期 + 诚实闸的价值。

## 4. 病灶指向的方法学修正（供未来迭代周期，非过拟合微调；用户定夺是否启动）

1. **重构合并口径**：把优质从「硬 AND 门」改为「软倾斜/权重」——让选股器在优质名单里始终保持仓位、再用投机形态做超配倾斜，根治空仓拖累。
2. **诚实汰形态**：按归因砍掉净负的突破临界/超跌反弹，保留/强化动量延续（唯一弱正）。
3. **或拆分关注点**：把「优质观察池」与「投机择时」分开，而非强行求交。
4. **基准意识**：long-only 选股器在牛市必须保持仓位，否则注定输给买入持有——这是 −42% 的根因。

## 5. 机制状态

Phase 1 基建——`rquant screen`（as-of 标注清单）+ `screen --backtest`（净值/标签归因/regime 切片/优质分层）+ 数据驱动集成配置 + 迭代裁决工具——**已建成、测试通过（17 单测）、clippy 干净、可复用**。需要迭代的是**方法学（信号与合并口径）**，不是机制。
