## v3 结构变更（相对 v2）

1. **吊灯止损锚定原版 N**：`close < max_price_since_entry - stop_n * ref(atr_v, bars_held)`——回撤倍数用信号 bar 时刻的 ATR（Turtle 原版口径，N 不随持仓期波动放大而漂移）；越窗/极值弃权 → 当前 N 的 2N 固定止损兜底。
2. **L1.5 冷却闸**：离场后 `cool_k` 根内不开新仓（阻断分支形态，打分模式 NaN 直通零影响）。
3. **失败突破窗口形**：`fb_up_age <= fb_k and close < fb_up_level and close < open`——事件按逐位滚动通道判定（barssince），锚价 = 破位时刻的通道价（valuewhen），替代 v2 的 1-bar ref 形。
4. **日内 VWAP 同侧过滤**：趋势回调入场确认加 `close >= session_vwap`（空头镜像 `<=`；`>=` 容当日首根退化）。

## 诚实判读

1. **不构成生产 go 信号**：绝对 Sharpe 上限 +0.35，单周期单年样本，且最近一季三标的 OS 全负。
2. **结构性进步是真实的**：600036 四参数零漂移（WFO 框架下最强的稳定性信号）；跌势样本中两只有 edge 标的的防守显著（回撤 4~6% vs 市场 −10%~−29%，超额 +9/+30pp）；000858 胜率 47.8%。
3. **标的筛选 > 参数调优**：同一棵树茅台恒负、招行/五粮液弱正——edge 的第一变量是标的与 regime，参数是第二位。组合层（top-N 横截面）天然内置这层筛选，是比单标的更合适的部署形态。
4. v4 候选杠杆（本轮刻意未动，留独立归因）：Turtle S1 跳过（`last_trip_return > 0` 阻断分支）、首小时区间引擎（session_high/low）、percentrank 自适应波动闸（替代固定 vol_floor/vol_cap）。
