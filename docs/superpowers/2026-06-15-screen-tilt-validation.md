# 选股器迭代 #1（优质驱动 + 动量倾斜）验证发现（诚实记录）

- 日期：2026-06-15
- 范围：在深 20 universe（2018-2026，rebalance=5，top=10）上验证 combine v2（优质驱动 + 动量倾斜），与 Phase-1（优质×投机 强 AND）对比。
- 结论一句话：**迭代 #1 被证伪——不仅没修好，反而更差；但它精确定位了真正的瓶颈是「优质树」本身（过稀 + 不预测），而非合并口径。**

## 2. 三个诚实发现

**① 动量倾斜毫无作用（λ=0 ≡ λ=1，逐位相同）。** 根因：`avg_members=1.00`——每个调仓点**仅约 1 只**股票满足 `quality≥0.5`。倾斜只改变合格池内的排名，池子是单元素时无可重排 → λ 完全失效（IT-2 单测证明倾斜逻辑正确；这里是池子退化，非 bug）。

**② 优质驱动比 Phase-1 更差（−76.2% vs −42%）。** 把"必须命中形态"的 AND 门去掉后，avg_members 从 0.38 升到 1.00（空仓拖累名义上缓解），但**没有变成分散的 top-10，而是坍缩成 ~1 只的集中押注**——最大回撤 82%、Sharpe −0.79。集中单票 + 调仓换手 → 比 Phase-1 的"多半空仓"还惨。

**③ 优质分本身不预测前瞻收益。** 优质分层 Q1(质0.66)/Q2(质0.89)/Q3(质1.0) 前瞻 −0.0002/−0.0117/−0.0003——**非单调、全≈负**。更高优质 ≠ 更高前瞻收益（Q2 反而最差）。

**regime（λ=1）**：2019-21 牛 picks −0.59 vs 基准 +2.73（超额 −3.32，踏空牛市）；2022 熊 picks −0.17 vs 基准 −0.27（+0.10，略防御）；2023-24 −0.11 vs +0.19（−0.30）。**每个 regime 都跑输。**

**标签归因**（不变，因倾斜失效）：动量延续 116 picks +0.27% 弱正；突破/超跌净负——与 Phase-1 一致。

## 3. 真正瓶颈：优质树（而非合并口径）

Phase-1 归咎于"AND 交集不相交"；迭代 #1 去掉 AND 后暴露了**更深的根因**：
- **过稀**：优质树（`close>ema200 且 ema50>ema200` + 流动性 + 距高点分级）给出 `quality≥0.5`（"good"/"excellent" 档）的标的，全历史**几乎每期只有 ~1 只** → 任何"优质驱动 top-N"都坍缩成单票，倾斜永远失效。
- **不预测**：即便放宽让更多入选，优质分层显示**技术优质分对前瞻收益无预测力**（非单调、全负）——放宽只会分散，不会跑赢。

合并口径（AND vs 优质驱动 vs 倾斜）从来不是核心问题；**优质信号的定义才是**。

## 4. 诚实立场（§5.3）

未调参美化。迭代 #1 的假设（优质驱动 + 动量倾斜能修好选股器）**被证伪**：combine v2 结构更合理（优质驱动 + 倾斜 比强 AND 干净），但**救不了一个过稀 + 不预测的优质信号**。这是有效产出——它把"问题在合并口径"证伪、定位到"问题在优质信号定义"。

## 5. 跨阶段收敛结论（重要）

Phase-1（AND 空仓）+ 迭代 #1（优质驱动坍缩单票）+ 深重验（4 棵树）三者收敛到同一事实：**在这 20 只大盘上，技术面信号（优质、择时触发树）都跑不赢买入持有；唯一反复显示弱正的是横截面动量**（动量延续标签 +0.27%；强度树条件 edge——但深重验已证其 Sharpe 1.43→0.63 腰斩）。

**若继续（用户定夺），方向不再是"修优质门"，而是二选一：**
1. **重新定义优质信号**——要既能放宽到可分散、又真有前瞻预测力（但分层证据表明技术优质本身不预测，前景存疑）；
2. **转向动量/强度驱动的选股器**——直接以横截面动量为选择轴（唯一反复弱正者），优质退为风控过滤。这绕回强度树方向，须正视其牛市高估/Sharpe 腰斩的已知问题。

诚实判断：证据越来越指向"这组大盘 + 纯技术信号"难以稳定跑赢等权买入持有；要么换信号族（如真做基本面，但本引擎 OHLCV-only），要么接受选股器作为风险调整/择时工具而非超额收益工具。
