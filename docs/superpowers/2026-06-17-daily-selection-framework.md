# 日频选股：回测-评估-Claude优化 循环框架

> 用户指令（2026-06-17）："如果用每天快进快出，每天尾盘买入卖出调仓一次这种方式呢？聚焦于选股而非对所有股票做策略决策，构建对于这种策略的回测评估 claude 优化的循环框架。"

本文档是该指令的交付物：一套**每日尾盘调仓、横截面选股**策略的回测+评估+迭代框架，以及用它跑出的诚实结论。沿用项目的**证伪文化**——证伪是合法且有价值的产出；本框架刻意把"净指标 + 换手"放在最显眼处，绝不为好看数字调参（§5.3 反过拟合）。

---

## 1. 边界与定位

- **策略形态**：每个交易日**尾盘**按横截面打分选出 top-N 只股票，等权持有 1 日，次日尾盘再调。即 `rquant screen --backtest --rebalance 1`。
- **聚焦"选股"**：决策是"今天持有哪 N 只"（cross-sectional selection），不是"对每只股票各自做买/卖时序决策"。引擎本就是横截面选股器（多树合并 → select_top）。
- **universe**：survivorship-free top-2000 月度成员（`--membership`），剔除幸存者偏差。
- **基准**：每日 top-2000 等权、无成本。这是一个**很强**的基准（等权天然偏小盘，2018-2026 累计 +105%）。

## 2. 引擎语义（已逐行验证，无前视）

| 项 | 实现 | 验证 |
|---|---|---|
| 尾盘日调 | `--rebalance 1` → 每个交易日一个调仓段 `(T, T+1)`，段收益 = `close[T]→close[T+1]` | `backtest.rs:199-210` 段构造；`accrue` 用 `last_close_at` |
| 无前视 | 打分在 T 仅见 `≤T` 的 bar（`trailing_visible`）、基本面 `as_of(t)`、aux `≤t` | `context.rs` `no_future_bar_leaks_property` 测试 |
| 成本 | 每调仓 `nav *= 1 − rate·Σ|Δw|`，`rate = cost_bps/2/10000`；满仓全换(Σ|Δw|=2.0) = `cost_bps` 个 bp | `portfolio.rs:66` `turnover_between` |
| 选股 | `select_top` 取 combined>0 的前 N（降序，确定性 tie-break） | combined = quality×(1+λ·tilt) |

**执行时点诚实声明**：模型在 `close[T]` 同时"决策+成交"（决策用到当日收盘价本身）。这比现实的"T 日尾盘决策、T+1 开盘成交"略乐观，但属 A 股尾盘策略的常规假设。真实部署应留意这点滑移。

## 3. 成本墙的算术（日频的核心矛盾，必须前置）

`cost_bps=20`（≈A股双边真实成本：佣金~2.5bp/边 + 印花税5bp卖出 + 滑点）下：
- 若选股**每日近乎全换**（Σ|Δw|≈2/日），日成本≈20bp → **年化≈50% 拖累**。日频选股**只有**两条出路：① 选股**高度黏滞**（日间持仓变化小、换手低）；② 毛 alpha 大到能覆盖换手成本。
- 框架因此把 **每调仓 Σ|Δw| / 单边日换手% / 年化换手倍数** 与 **gross→net 衰减 / break-even 成本** 作为一等公民输出。

## 4. 框架三件套

### 4.1 配置约定：纯信号选股器
把"选股信号"放在 `quality_trees`，`lambda: 0` → `combined = quality`（tilt 被乘 0），`select_top` 直接按信号强度选。同一棵树登记为一个 `setup` 仅为满足校验（`setup_trees`/`tilt_setups` 非空）并提供标签归因，不影响选股。示例：`examples/screen/daily_reversal_v1.yaml`、`daily_value_v1.yaml`、`daily_momentum_v1.yaml`、`daily_lowvol_v1.yaml`。

> 信号权重表达式必须在 (0,1) 正单调（`select_top` 滤 >0、叶 weight 自动 clamp [0,1]）——用 `sigmoid(...)` 或 `1/(1+x)`。

### 4.2 评估器：`scripts/daily_eval.py`
对一个配置以 `--rebalance 1` 跑两次（gross cost=0 / net cost=20），解析 JSON，输出日频该看的诊断：
```
python scripts/daily_eval.py examples/screen/<cfg>.yaml [--cost 20] [--top N] [--from .. --to ..]
```
输出：调仓次数、每调仓 Σ|Δw|、单边日换手%、年化换手倍数、毛/净（总收益·基准·超额·Sharpe·回撤）、成本衰减、**break-even 成本(bp)**、各 regime 毛/净超额、**诚实裁决**。

### 4.3 诚实判读准则（"好"的日频选股器门槛）
1. **源头闸**：毛超额 > 0。毛都 ≤0 → 信号源头无 alpha，成本无关，直接证伪。
2. **OOS 金标准**：净 OOS(2023-25) 超额 > 0 且 净全样本 Sharpe > 0。
3. **稳健性**：跨平凡参数（top、再平衡频率、回看窗）不符号翻转；多 regime 不靠单一窗口。
4. **换手可承受**：break-even 成本显著高于真实成本（≥2×，留安全垫）。
全部满足才"未证伪"。任一不满足 → 证伪并记录原因。**绝不调参凑过线**。

## 5. Claude 优化循环协议
```
1) 写/改一个纯信号选股树 + daily_*.yaml 配置
2) python scripts/daily_eval.py <cfg>          # 回测+评估（gross/net/换手/break-even/裁决）
3) 读裁决与 regime 切片 → 诚实判读（PASS / 证伪+原因）
4) 若证伪：记入研究日志，换"真新角度"（不重测已证伪族、不钓参数变体）
   若 PASS：加稳健性扫描（top/reb/window/cost）+ 子样本 OOS 复核
5) 回到 1
```
数据基础设施已就绪（top-2000 survivorship-free、point-in-time 基本面），单次全样本日频回测 ~100s，循环可快速迭代。

## 6. 已跑基线（2018-2026，top-50，net cost 20bp；基准=top-2000 EW 无成本）

| 选股器 | 毛超额 | 净超额 | 净Sharpe | 净maxDD | 每调仓Σ|Δw| | OOS净超额 | 裁决 |
|---|---|---|---|---|---|---|---|
| 短期反转(5日跌幅最大) | **−1.99** | −2.04 | −1.39 | 0.99 | 1.01 | −1.33 | **灾难证伪**（毛即崩；极端跌者续跌）|
| 纯价值(PB最低) | −0.62 | −0.78 | 0.15 | 0.28 | 0.062 | −0.32 | 证伪(超额)；仅防御（低换手、低回撤、lag基准）|
| 纯动量(N日涨幅最大) | **−2.01** | −2.03 | −1.01 | 0.99 | 0.47 | −1.28 | **灾难证伪**（毛即崩；极端涨者续跌）|
| 纯低波(20日波动最低) | −0.74 | −1.35 | −0.29 | 0.43 | 0.306 | −0.50 | **证伪（成本墙样板）**：毛 +30.6% 但净 −29.9%，中换手×日成本吞掉 −60% 超额 |

**数据可用性铁律**：基本面 CSV 最早 2019-04-30（首份财报）。基本面类选股器（价值）在 2018 全员弃权 → 空仓 → 2018 regime "防御 +0.29" 是**无数据伪影**，须丢弃；价值的有效评估窗 = 2019-05 起。纯价格类（反转/动量/低波）2018 起全有数据。

**反转细节**：质量分层显示中间分位有**微弱**真反转（Q5最跌者次日 +0.0005/日 vs Q1 −0.0008/日），但实际选中的**最极端** top-50 跌者次日续跌——A股 2018-2026 弱市里"接落刀"是绞肉机，每个 regime（含 2019-21 牛市 −1.61）皆深度为负。

**四象限综合（日频选股为何难，框架给出的诊断）**：
1. **极端价格因子（动量/反转）→ 源头无 alpha**：买最极端的涨者或跌者，毛收益即 −96%/−94%。极端日间波动者在 top-2000 里两个方向都是绞肉机（彩票/关注度毒性、idiosyncratic 崩跌），与成本无关。
2. **中换手防御因子（低波）→ 成本墙处死**：有微弱正毛收益（+30%）但 15%/日换手 × 日成本 = 净 −30%。这正是日频的核心矛盾——`break-even` 成本 < 真实成本。
3. **低换手防御因子（价值）→ 扛得住成本但无超额**：换手仅 3%/日（慢信号日调几乎不变），净 Sharpe 0.15、回撤低，但相对强 EW 基准无超额，只防御不增益；且日调相对季调纯属多付成本无收益。
4. **结论**：要在日频选股跑赢强 EW 基准，需要一个"毛 alpha 为正 **且** 换手低到成本扛得住"的信号——四象限里无一兼得。这与 25 轮慢调仓结论同源：A股 top-2000 上价值-防御是唯一稳健边，且它的最优形态是慢调仓、不是日频。

## 7. 与 25 轮历史结论的衔接
此前 25 轮（慢调仓 reb20-60）已把价值/质量/成长 + 全套技术趋势振荡价格行为 + 规模代理作横截面选股证伪，唯一稳健边是**价值-防御**。日频框架是**新方法学轴**（再平衡频率 + 尾盘执行 + 自动化评估循环），其首批结论与历史一致：把调仓提到日频不改变信号的有无——反转日频灾难、价值日频仍只防御不增 alpha。日频的**唯一**新意义在于：① 验证了引擎忠实建模尾盘日调且无前视；② 量化了换手成本墙（价值低换手/反转高换手）；③ 交付了可复用的日频选股评估循环工具。
