# 量化策略中文名册 (strategy Chinese names)

把迭代账本里 label 形如 `garp_rev` 的策略对应到**可读中文名 + 一句话定位 + 裁决**。
完整逐轮指标见 [iteration-ledger.md](superpowers/iteration-ledger.md)（单一事实源）；配置在 `examples/screen/iter/`。
口径统一：A股日线 universe 1073、月频(reb20)、净 20bps、train 2018–23 / OOS 2024–26、基准=可交易宽基指数。

> ★ = 当前推荐赢家族。命名为研究展示用；如需在客户端「选股」页显示中文名，是一个独立特性（待 brainstorm→spec→plan）。

## 命名规律（约定）

- **价值类**：低 PB=「深价值」、低 PE=「低估值(PE)」。
- **成长类**：净利增速=「净利成长」、营收增速=「营收成长」。
- **质量类**：ROE=「高质量」、毛利率=「高毛利」。
- **组合**：价值闸+成长 tilt=「(因子)合理价」/GARP 系；多树均值=「N因子均衡」。
- **后缀**：`·行业中性`（每行业 top-k）、`·可投资`（盈利+流动性地板）。
